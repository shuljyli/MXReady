# MXReady

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Português](README.pt-BR.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | **Русский**

Код на PyTorch работает на видеокартах NVIDIA, и его нужно перенести на GPU MetaX. Что именно сломается — пока непонятно.

MXReady читает код, не запуская его, и показывает места, которые с большой вероятностью создадут проблемы:

- где напрямую вызывается компилятор NVIDIA;
- где жёстко заложены группы по 32 потока (в MetaX их 64);
- где используется встроенный ассемблер, доступный только на NVIDIA;
- где есть зависимость от библиотеки, которой нет на новой карте.

Для каждой находки указаны файл, строка, причина и предложение по исправлению.

## Как пользоваться

Скачайте ZIP для своей системы, распакуйте и запустите установщик.

```bash
# Linux / macOS
bash install.sh
bash start.sh
```

```powershell
# Windows
.\install.ps1
.\start.ps1
```

Затем откройте <http://127.0.0.1:8000> и вставьте адрес репозитория.

Из командной строки тоже работает:

```bash
mxready-scan ./my-repo \
  --repo-url https://github.com/example/my-repo \
  --commit <40-символьный коммит> \
  --output reports
```

## Чего он не делает

- Не переписывает ваш код.
- Не выдаёт «процент совместимости». Количество сработавших правил ничего не говорит о том, заработает проект или нет.
- Чистая статическая проверка означает лишь то, что ничего очевидного не найдено. Настоящий ответ даёт запуск того же коммита на машине MetaX.
